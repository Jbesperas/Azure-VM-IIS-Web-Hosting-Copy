
# Azure VM and IIS Web Hosting

This repository contains my documentation for our Microsoft Azure practical activity.

In this activity, I created a virtual machine in Azure, installed Internet Information Services (IIS), and hosted a basic website on the virtual machine.

I also tried deploying the website using Azure Static Web Apps and GitHub.

## What I Did

- Created and configured an Azure Virtual Machine
- Installed IIS for web hosting
- Hosted a basic website using the VM
- Created an Azure Static Web App
- Connected GitHub for deployment

## Results

I was able to display the website using the Azure VM and Azure Static Web Apps.

Screenshots of the results are included in my documentation.
